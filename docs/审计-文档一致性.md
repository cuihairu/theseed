## 四段式总账

**① 方法与覆盖**：按规范枚举 README（en/zh）、docs/** 全部 94 个 md 页面、设计文档、公开面；每条主张逐条对码取证（含否定性结论先验证路径存在——XSD 结论前已确认 `tools/` 无 defcheck、仓内无 `*.xsd`）。

**② 发现与修复**：13 条（P0×1、P1×3、P2×5、P3×4）。已修 12 条；B5 记录不修（示意清单）。修复方向均为改文档，未改任何产品码。

**③ 关键动作**：①交换 docs/design 与 docs/zh/design 两棵内容树（44 文件）+ architecture/KNOWN_UNCOVERABLE_ARMS 两对，使 root=英文、zh=中文；②规整 90+ 文件的语言切换注释行；③修复 en/zh README 徽章（单行居中、语言正确、双斜杠清零）；④补 README 的 PostgreSQL 后端与 THESEED_HAS_POSTGRESQL；⑤更新陈旧测试数 115→120；⑥persistence.md §6 的 ✅ 降级为设计目标；⑦设 GitHub About（description+topics）；⑧todo.md 重整为需求台账（1777 行 → 42 行）。

**④ 验证**：`vitepress build` 通过（65.55s，构建产物语言抽查：root=英文、zh=中文）；`cmake --preset gcc-debug` 全量构建通过（684 目标），ctest **118/120 全绿**——`theseed_login_app_e2e_test` 与 `theseed_machine_daemon_test` 在本环境失败（根因：本机 992 进程使 `LocalProcessSupervisor::listProcesses()` 枚举 ~15s，超出测试 2-4s 时间预算；作者环境记录 120/120 全绿）。本审计改动为纯文档，不影响测试结果；两失败为环境性、非回归。docs 站点无独立 VitePress 新建（已有站点，本次修正语言倒置）。
